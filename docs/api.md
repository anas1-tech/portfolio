# API reference

Base path: `/api`. JSON in and out. Interactive docs for the owner: sign in at `/admin/`, then open **`/api/docs/`** (Swagger UI, generated by drf-spectacular). The raw schema is at `/api/schema/`.

**Auth:** send `Authorization: Token <token>` (from `POST /api/auth/login/`). "Public" endpoints need no token.

| Method & path | Access | Description |
|---|---|---|
| `GET /portfolio/` | public | Everything the site needs: `{settings, experiences, skills, courses, projects}` |
| `GET /settings/` | public | Site settings (single object) |
| `PATCH /settings/` | staff | Update settings |
| `GET/POST /experiences/` · `GET/PATCH/PUT/DELETE /experiences/{id}/` | read public, write staff | `type` is `exp` or `edu` |
| `GET/POST /skills/` · `/skills/{id}/` | read public, write staff | |
| `GET/POST /courses/` · `/courses/{id}/` | read public, write staff | |
| `GET/POST /projects/` · `/projects/{id}/` | read public, write staff | `techs`: list, or comma string in multipart; `image`: file |
| `POST /contact/` | public, 5/hour | `{name, email, message, website?}`; `website` is a honeypot |
| `POST /auth/login/` | public, 10/min | `{username, password}` → `{token}`; staff accounts only |
| `POST /auth/logout/` | token | Invalidates the token (204) |
| `GET /auth/me/` | public | `{is_admin: bool}` |
| `GET /system/` | staff | Service links, DB host/port/name/user (no password), connection check, content counts |

## Conventions

- Bilingual fields come in pairs: `title_ar`, `title_en`, `desc_ar`, ... The Arabic field is required where it is the primary label (title/name).
- Validation errors: `400` with `{ "field": ["message", ...] }`.
- `401` unauthenticated write · `403` authenticated but not allowed · `429` rate limited.
- Image uploads use `multipart/form-data`; everything else is JSON.

## Examples

```bash
# public read
curl http://localhost:8080/api/portfolio/

# sign in, then add a skill
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login/ \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"..."}' | jq -r .token)

curl -X POST http://localhost:8080/api/skills/ \
  -H "Authorization: Token $TOKEN" -H 'Content-Type: application/json' \
  -d '{"name_ar":"القيادة","name_en":"Leadership"}'

# project with an image and tags
curl -X POST http://localhost:8080/api/projects/ \
  -H "Authorization: Token $TOKEN" \
  -F title_ar="مشروع" -F techs="React, Django" -F image=@shot.png
```
